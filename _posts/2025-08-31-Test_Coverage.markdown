로그인 기능과 장바구니 기능을 예시로 테스트 케이스 작성 → 커버리지 측정 과정을 보여드릴게요.

## 1. 로그인 기능 예시
# (1) 요구사항

올바른 아이디 + 비밀번호 입력 시 → 로그인 성공

잘못된 아이디 입력 시 → "계정 없음" 오류

올바른 아이디 + 잘못된 비밀번호 → "비밀번호 오류"

5회 연속 실패 시 → 계정 잠김

# (2) 테스트 케이스
|TC ID|입력 조건|예상 결과|
|---|---|---|
|TC01|valid ID + valid PW|로그인 성공 → 메인 이동|
|TC02|invalid ID + any PW|"계정 없음" 오류|
|TC03|valid ID + invalid PW|"비밀번호 오류"|
|TC04|valid ID + invalid PW, 5회 반복|계정 잠김|


# (3) 커버리지

Line Coverage: 로그인 함수 내의 주요 코드 줄은 모두 실행됨

Branch Coverage:

if (id 존재) 조건 O/X → 커버됨

if (비밀번호 일치) 조건 O/X → 커버됨

if (실패횟수 >= 5) 조건 O/X → 커버됨

결과: 100% Branch Coverage 달성

## 2. 장바구니 기능 예시

# (1) 요구사항

상품 추가 → 장바구니에 담김

동일 상품 추가 시 → 수량 증가

수량 감소 시 0 이하 → 상품 제거

장바구니 비었을 때 → "장바구니가 비었습니다" 메시지 표시

# (2) 테스트 케이스
|TC ID|입력 조건|예상 결과|
|---|---|---|
|TC01|장바구니 비어있음 + 상품 A 추가|장바구니 = {A:1}|
|TC02|장바구니 {A:1} + 상품 A 추가|장바구니 = {A:2}|
|TC03|장바구니 {A:2} + 상품 A 수량 감소(1)|장바구니 = {A:1}|
|TC04|장바구니 {A:1} + 상품 A 수량 감소(1)|장바구니 비움 메시지 표시|
|TC05|장바구니 비었을 때 "결제하기" 클릭|"장바구니가 비었습니다" 메시지|

# (3) 커버리지

Line Coverage:

addItem(), removeItem(), checkout() 내의 모든 코드 줄 실행됨

Branch Coverage:

if (상품 존재) O/X → 모두 커버

if (수량 == 0) O/X → 모두 커버

if (장바구니 비었음) O/X → 모두 커버

결과: 테스트 케이스 5개로 모든 분기문 검증 → Branch Coverage 100%

## 3. 정리

테스트 케이스를 요구사항에 맞게 작성 → 각각 실행

커버리지를 측정 → 코드의 어떤 부분이 실제 테스트되었는지 확인

로그인 / 장바구니 기능 모두 Branch Coverage 100% 달성 가능
